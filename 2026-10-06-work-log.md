### 3.2 Key design decisions

- **Defaults** (per event, materialised on first admin save): `QUESTION_ASSIGNED` in-app+push · `REVIEW_REMINDER` in-app+push · `QUESTION_REVIEWED` / `QUESTION_UNASSIGNED` in-app only (push off) · email off everywhere until SMTP/Resend is configured.
- `notify()` **never throws** — a broken push/email path must never fail the business action that triggered it.
- Reminder de-dupe: `dedupeKey = reminder:<bucket>` (bucket = `floor(now / hours*3600e3)`) + in-memory 6h guard + DB unique index `(userId, dedupeKey)`; sweep throttled 5 min/school.
- SW suppresses the system notification when a visible tab exists (the page toast already shows it) → no double notification.
- Push payload shape: `{ title, body, url, tag, type }`.
- Missing VAPID keys ⇒ push is silently skipped, in-app still works.
